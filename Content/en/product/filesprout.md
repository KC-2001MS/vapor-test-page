# FileSprout
FileSprout is a menu bar app that lets you create empty files with any name and extension, anytime. It reduces the hassle of creating files in apps and streamlines your workflow.

FileSprout has the following features
- Set the file name and extension before creating the file, so there is no need to rename it later
- Add a file just by dragging it from the menu bar into Finder or another app
- Copy a file to the clipboard and paste it wherever you like
- Copy a file to the clipboard with one click from a control you can place in Control Center
- Launch automatically at login

## How to use
1. Click the FileSprout icon in the menu bar
2. Enter a file name and extension
3. Drag the file to where you want to add it, or copy it to the clipboard and paste it
