# SSH Key Wallet
SSH Key Wallet is the easiest way to manage SSH encryption keys and SSH Config files in ~/.ssh/ based on OpenSSH. You can freely create, delete and edit keys, with no need to use terminal-based command line tools to manage your encryption keys.

SSH Key Wallet has the following features
- Create, delete and edit encryption keys
- Easily copy private and public key values
- Edit the configuration of encryption keys
- Configure SSH connections with the SSH Config file and edit the Config file
