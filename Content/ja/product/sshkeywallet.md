# SSH Key Wallet
SSH Key Walletは、OpenSSHをベースとした~/.ssh/内のSSH暗号鍵とSSH Configファイルを最も簡単に管理する方法です。暗号鍵を自由に作成・削除・編集でき、ターミナルのコマンドラインツールを使わずに暗号鍵を管理できます。

SSH Key Walletには以下の特徴があります。
- 暗号鍵の作成・削除・編集
- 秘密鍵・公開鍵の値の簡単なコピー
- 暗号鍵の設定の編集
- SSH ConfigファイルによるSSH接続の設定とConfigファイルの編集
