# 麻雀の牌姿を表現するMPSZ形式

MPSZ形式は、麻雀の牌姿（手牌などの牌の並び）を、数字とm・p・s・zの4文字だけで書き表す記法です。キーボードで入力でき、特別なフォントや画像も必要ないため、SNSやブログ、麻雀ツールの入力などで広く使われています。

例えば、次の牌姿はMPSZ形式で`123m456p789s11z`と書けます。

<p class="mahjongTiles">🀇🀈🀉🀜🀝🀞🀖🀗🀘🀀🀀</p>

## 基本のルール

### 牌は「数字＋牌種の文字」で表す

1枚の牌は、数字と、牌の種類を表す文字の組み合わせで表します。

| 文字 | 牌の種類 | 数字の範囲 | 例 |
| ---- | ---- | ---- | ---- |
| m | 萬子（マンズ） | 1〜9 | `1m` = <span class="tile">🀇</span> |
| p | 筒子（ピンズ） | 1〜9 | `1p` = <span class="tile">🀙</span> |
| s | 索子（ソーズ） | 1〜9 | `1s` = <span class="tile">🀐</span> |
| z | 字牌（ジハイ） | 1〜7 | `1z` = <span class="tile">🀀</span>（東） |

字牌は、`1z`〜`7z`が東・南・西・北・白・發・中の順に対応します。

### 同じ種類が続くときは、文字をまとめられる

同じ種類の牌が続くときは、数字だけを並べて最後に1回だけ文字を書きます。

- `1m2m3m` → `123m`
- `1m2m3m4p4p` → `123m44p`

数字は「次に現れる文字」の種類として読まれます。そのため、`123m44p`は「1・2・3が萬子、4・4が筒子」という意味になります。

### 赤牌は0で表す

赤ドラの5は、5の代わりに`0`を使って表します。

- `0m` = <span class="tile" style="color:red">🀋</span>（赤五萬）
- `0p` = <span class="tile" style="color:red">🀝</span>（赤五筒）
- `0s` = <span class="tile" style="color:red">🀔</span>（赤五索）

## 拡張された書き方

次の書き方は、一部のツール（[麻雀牌コンバータ](/product/mahjongtileconverter)など）で使えます。対応していないツールもあるため、ご注意ください。

| 書き方 | 意味 | 例 |
| ---- | ---- | ---- |
| `r`＋牌 | 赤牌（`0`と同じ） | `r5m` = <span class="tile" style="color:red">🀋</span> |
| `-` | 牌の裏面 | `-` = <span class="tile">🀫</span> |
